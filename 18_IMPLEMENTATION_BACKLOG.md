# Purpose

Документ декомпозирует Roadmap на независимые задачи разработки.

Каждая задача:

- имеет измеримый результат;
- может быть выполнена одним разработчиком;
- занимает не более одного рабочего дня;
- имеет чёткий критерий завершения;
- содержит зависимости.
